FOLHA RURAL - PROTOTIPO FUNCIONAL
=================================

INSTALACAO NA UNIDADE D:

1. Extraia a pasta "App Folha Rural" para a unidade D:.
   O caminho final deve ficar assim:

   D:\App Folha Rural

2. Instale o Node.js LTS pelo site https://nodejs.org/ caso ainda nao esteja instalado.

3. Dentro da pasta, execute INSTALAR.bat uma unica vez.

4. A instalacao criara automaticamente o atalho "Folha Rural" na Area de Trabalho.

5. Use o atalho para abrir o sistema. Se ele for removido, execute CRIAR-ATALHO.bat.

6. O sistema sera executado em segundo plano, sem manter uma janela preta aberta.

7. Para encerrar completamente o servidor local, execute FECHAR-FOLHA-RURAL.bat.

SE O NAVEGADOR INFORMAR CONEXAO RECUSADA

O novo iniciador espera o servidor ficar pronto antes de abrir o navegador.
Se ainda houver falha, consulte logs\inicializacao.log e execute INSTALAR.bat novamente.
Confirme tambem que o Node.js instalado e a versao 22 ou superior.
Para mostrar o diagnostico em uma janela, execute TESTAR-FOLHA-RURAL.bat.

IMPORTACAO DO ACCESS

1. Abra o Folha Rural pelo atalho.
2. Entre no menu Importar Access.
3. Selecione o arquivo Folha-Fazenda DB.mdb no seu computador.
4. Confira os totais antes de confirmar: 268 pessoas provisórias, 735 contratos e 20 ativos.
   Das 268 pessoas, 266 possuem CPF válido distinto e 2 exigem conferência cadastral.
5. Confirme somente se os numeros estiverem corretos.

Os contratos ativos receberao matriculas novas iniciando em 1 por empresa.
Os contratos desligados receberao codigo LEG e manterao a matricula antiga no mapa de migracao.

IMPORTANTE

Esta entrega corresponde ao prototipo navegavel atual. Os dados exibidos sao demonstrativos.
Ela ainda nao deve ser utilizada para calcular ou pagar uma folha real.

As proximas etapas do projeto incluem login e permissoes, cadastros completos,
apontamentos persistentes, feriados, DSR,
motor de calculo, recibos, relatorios e validacao das regras trabalhistas.

O banco Access original nao foi incluido neste pacote para proteger os dados pessoais.
